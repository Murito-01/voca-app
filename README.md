# **Description**

A reward-based survey and feedback platform with a validated respondent system, anti-fraud, and instant payouts, enabling startups and businesses to obtain high-quality data quickly and affordably. A survey platform with validated respondents and a reputation-based quality system.

# Goals

- Create a platform for creating and completing surveys, as well as an automated reward system.
- Integrated system with e-wallets for withdrawing rewards.
- Multi-platform, including mobile and web.
- Not just for surveys, but also a platform for people to get feedback on their MVPs.
- Instant rewards after completing surveys.

# Tech

- React (Frontend)
- Next.js (Backend)
- Supabase (Database)
